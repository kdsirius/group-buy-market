## 每节的教学流程（草案，待确认）

1. **本节要解决什么问题** —— 只看原文「本章诉求 / 业务流程」，先不碰代码。
2. **老师怎么解的** —— 在参考分支上定位新增类，讲结构：新增了哪些接口/类，谁调谁，为什么这样分层。
3. **对照自己的工程** —— 把参考类映射到 `com.sirius` 下的对应位置；指出哪些类需要新建、哪些需要改。
4. **关键实现** —— 只展开 1~2 处核心代码（如责任链的组装、模板方法的钩子），其余留给自读。
5. **自检问题** —— 3 个左右的问题，答得上来再进下一节；不代写练习代码。
