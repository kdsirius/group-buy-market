# 19 / 2-15：页面要什么，接口就组织什么

> 上一节是“看起来能买”的静态页面。这节先做好两扇后端门：**查询首页数据、模拟支付后结算**。下一节再由我接页面，不要求你手敲前端。
> 对应[原文第19节](../orgin-tutorial/2.第2部分：服务实现/19-2-15-根据UI展示封装接口.md)，参考 `reference/group-buy-market` 的 `2-15-250203-xfg-ui-http`，不使用后续分支能力。

## 0. 先定边界

本节后端由你手敲；没有新设计模式要背，也不用装 ApiPost 插件或上传项目。先跑不连数据库的测试，再按步骤调用本机接口。

两条路径：

```text
查询：请求商品与用户 → 优惠试算 → 可展示团列表 → 活动统计 → 一个JSON响应
结算：请求用户、外部单号、支付时间 → 已有结算服务 → 返回结算结果
```

**这不是生产支付回调**：调用方传入的 userId 和支付时间尚无认证/验签。接口只在隔离的本机学习环境演示，不能公网开放、不能将浏览器“支付完成”当银行付款凭证。`@CrossOrigin` 也不是认证。

### 为什么不能直接把数据库表返回给页面？

页面同时需要商品价格、团进度和统计，但这些分散在不同表中。如果直接返回 PO，会泄漏存储结构；还可能顺带暴露通知地址等页面不需要的信息。

所以响应按用途分三块，像把食材装成一份套餐：

| 页面位置 | JSON字段 | 来源 |
| --- | --- | --- |
| 原价/优惠/实付 | `data.goods` | 复用优惠试算，不让前端算价格 |
| “我的团”与其他团 | `data.teamList` | 明细定位用户/外部单号，团表提供人数与截止 |
| 团数、成团数、参与量 | `data.teamStatistic` | 按活动聚合统计 |

`Response<T>` 外壳里的 `code/info` 表达业务结果，`data` 是这份套餐。HTTP 200 不等于 `code=0000`。

## 1. 先定数据口径，再写SQL

本节不改表结构。先读这些约定：

- “可展示团”要求：进行中、未锁满、**团截止时间在未来**。明细的 `end_time` 是活动时间，不拿它冒充团截止。
- 自己的团优先最多1条；其他用户取最近候选，再在 Java 打乱取最多2条。不是全库均匀随机，也不保证总能凑齐3个不同团。
- 合并按 teamId 去重，避免同一团的多条用户明细占满列表；候选先限量，所以去重后可能少于2条，不额外补查。
- 统计范围是试算关联的**活动**，不是所有商品/渠道的全站统计。`allTeamUserCount` 目前按 `sum(lock_count)` 算参与名额，不是去重自然人，也不等于付款人数。
- 没有团时：列表 `[]`，统计三个 `0`，不能生成 `IN ()` 或返回金额/计数 null。
- 倒计时用“截止时间减现在”，不是减开团时间；它只是展示快照，真正结算仍查后端时间规则。

与参考的必要差异：直接按活动统计，避免先查明细再 `GROUP BY` 非聚合列及空集合；查询时补团截止过滤；明确去重与空数据；倒计时不按24小时取模。原有锁单上限、结算幂等历史问题不在这里顺手修。

@Override
public List<UserGroupBuyOrderDetailEntity> queryInProgressUserGroupBuyOrderDetailListByOwner(
        Long activityId, String userId, Integer ownerCount) {
    GroupBuyOrderList request = new GroupBuyOrderList();
    request.setActivityId(activityId);
    request.setUserId(userId);
    request.setCount(ownerCount);
    return assembleTeams(groupBuyOrderListDao.queryInProgressUserGroupBuyOrderDetailListByUserId(request));
}

@Override
public List<UserGroupBuyOrderDetailEntity> queryInProgressUserGroupBuyOrderDetailListByRandom(
        Long activityId, String userId, Integer randomCount) {
    GroupBuyOrderList request = new GroupBuyOrderList();
    request.setActivityId(activityId);
    request.setUserId(userId);
    request.setCount(randomCount * 2);
    // DAO返回的候选复制后再打乱，避免修改调用方提供的列表。
    List<GroupBuyOrderList> rows = new ArrayList<>(
            groupBuyOrderListDao.queryInProgressUserGroupBuyOrderDetailListByRandom(request));
    Collections.shuffle(rows);
    if (rows.size() > randomCount) rows = rows.subList(0, randomCount);
    return assembleTeams(rows);
}

private List<UserGroupBuyOrderDetailEntity> assembleTeams(List<GroupBuyOrderList> rows) {
    // 无候选就结束，否则批量SQL会出现IN ()。MyBatis的列表查询无结果返回空List。
    if (rows.isEmpty()) return Collections.emptyList();
    Set<String> ids = rows.stream().map(GroupBuyOrderList::getTeamId).collect(Collectors.toSet());
    Map<String, GroupBuyOrder> teams = groupBuyOrderDao.queryGroupBuyProgressByTeamIds(ids)
            .stream().collect(Collectors.toMap(GroupBuyOrder::getTeamId, team -> team));
    List<UserGroupBuyOrderDetailEntity> result = new ArrayList<>();
    for (GroupBuyOrderList row : rows) {
        GroupBuyOrder team = teams.get(row.getTeamId());
        // 两次查询间团可能已满或截止，以第二次查到的可展示团为准。
        if (team == null) continue;
        result.add(UserGroupBuyOrderDetailEntity.builder()
                .userId(row.getUserId()).teamId(team.getTeamId()).activityId(team.getActivityId())
                .targetCount(team.getTargetCount()).completeCount(team.getCompleteCount())
                .lockCount(team.getLockCount()).validStartTime(team.getValidStartTime())
                .validEndTime(team.getValidEndTime()).outTradeNo(row.getOutTradeNo()).build());
    }
    return result;
}

@Override
public TeamStatisticVO queryTeamStatisticByActivityId(Long activityId) {
    return TeamStatisticVO.builder()
            .allTeamCount(groupBuyOrderDao.queryAllTeamCount(activityId))
            .allTeamCompleteCount(groupBuyOrderDao.queryAllTeamCompleteCount(activityId))
            .allTeamUserCount(groupBuyOrderDao.queryAllUserCount(activityId)).build();
}
```

这里抽 `assembleTeams` 是因为个人/他人两条路径确实共用批量组装，不是为未来猜需求。领域只认仓储接口，不 import DAO。

@Override
public List<UserGroupBuyOrderDetailEntity> queryInProgressUserGroupBuyOrderDetailList(
        Long activityId, String userId, Integer ownerCount, Integer randomCount) {
    // 有序Map保留第一次出现的团：自己的优先，再加入其他候选。
    Map<String, UserGroupBuyOrderDetailEntity> teams = new LinkedHashMap<>();
    if (ownerCount > 0) {
        for (UserGroupBuyOrderDetailEntity team : repository
                .queryInProgressUserGroupBuyOrderDetailListByOwner(activityId, userId, ownerCount)) {
            teams.putIfAbsent(team.getTeamId(), team);
        }
    }
    if (randomCount > 0) {
        for (UserGroupBuyOrderDetailEntity team : repository
                .queryInProgressUserGroupBuyOrderDetailListByRandom(activityId, userId, randomCount)) {
            teams.putIfAbsent(team.getTeamId(), team);
        }
    }
    return new ArrayList<>(teams.values());
}

@Override
public TeamStatisticVO queryTeamStatisticByActivityId(Long activityId) {
    return repository.queryTeamStatisticByActivityId(activityId);
}
```

`putIfAbsent` 是Java 8的Map方法：键不存在才放入。不会拿他人的候选覆盖自己同团那条、丢掉自己的外部单号。

import lombok.extern.slf4j.Slf4j;
import org.apache.commons.lang3.StringUtils;
import org.springframework.web.bind.annotation.*;
import javax.annotation.Resource;
import java.util.ArrayList;

@Slf4j
@RestController
@CrossOrigin("*")
@RequestMapping("/api/v1/gbm/index/")
public class MarketIndexController implements IMarketIndexService {
    @Resource
    private IIndexGroupBuyMarketService indexGroupBuyMarketService;

    @PostMapping("query_group_buy_market_config")
    @Override
    public Response<GoodsMarketResponseDTO> queryGroupBuyMarketConfig(@RequestBody GoodsMarketRequestDTO request) {
        if (StringUtils.isAnyBlank(request.getUserId(), request.getSource(),
                request.getChannel(), request.getGoodsId())) {
            return Response.<GoodsMarketResponseDTO>builder()
                    .code(ResponseCode.ILLEGAL_PARAMETER.getCode())
                    .info(ResponseCode.ILLEGAL_PARAMETER.getInfo()).build();
        }
        try {
            TrialBalanceEntity trial = indexGroupBuyMarketService.indexMarketTrial(MarketProductEntity.builder()
                    .userId(request.getUserId()).source(request.getSource())
                    .channel(request.getChannel()).goodsId(request.getGoodsId()).build());
            Long activityId = trial.getGroupBuyActivityDiscountVO().getActivityId();
            List<UserGroupBuyOrderDetailEntity> details = indexGroupBuyMarketService
                    .queryInProgressUserGroupBuyOrderDetailList(activityId, request.getUserId(), 1, 2);
            TeamStatisticVO statistic = indexGroupBuyMarketService.queryTeamStatisticByActivityId(activityId);

            // 同一次响应用同一个now算倒计时，DTO不泄露完整活动/折扣配置。
            Date now = new Date();
            List<GoodsMarketResponseDTO.Team> teams = new ArrayList<>();
            for (UserGroupBuyOrderDetailEntity detail : details) {
                teams.add(GoodsMarketResponseDTO.Team.builder()
                        .userId(detail.getUserId()).teamId(detail.getTeamId()).activityId(detail.getActivityId())
                        .targetCount(detail.getTargetCount()).completeCount(detail.getCompleteCount())
                        .lockCount(detail.getLockCount()).validStartTime(detail.getValidStartTime())
                        .validEndTime(detail.getValidEndTime())
                        .validTimeCountdown(GoodsMarketResponseDTO.Team.differenceDateTime2Str(now, detail.getValidEndTime()))
                        .outTradeNo(detail.getOutTradeNo()).build());
            }
            return Response.<GoodsMarketResponseDTO>builder()
                    .code(ResponseCode.SUCCESS.getCode()).info(ResponseCode.SUCCESS.getInfo())
                    .data(GoodsMarketResponseDTO.builder()
                            .goods(GoodsMarketResponseDTO.Goods.builder().goodsId(trial.getGoodsId())
                                    .originalPrice(trial.getOriginalPrice()).deductionPrice(trial.getDeductionPrice())
                                    .payPrice(trial.getPayPrice()).build())

@RequestMapping(value = "settlement_market_pay_order", method = RequestMethod.POST)
@Override
public Response<SettlementMarketPayOrderResponseDTO> settlementMarketPayOrder(
        @RequestBody SettlementMarketPayOrderRequestDTO request) {
    if (StringUtils.isAnyBlank(request.getUserId(), request.getSource(), request.getChannel(),
            request.getOutTradeNo()) || request.getOutTradeTime() == null) {
        return Response.<SettlementMarketPayOrderResponseDTO>builder()
                .code(ResponseCode.ILLEGAL_PARAMETER.getCode())
                .info(ResponseCode.ILLEGAL_PARAMETER.getInfo()).build();
    }
    try {
        // Controller只转换入参；时间与订单规则仍交给已有领域服务。
        TradePaySettlementEntity result = tradeSettlementOrderService.settlementMarketPayOrder(
                TradePaySuccessEntity.builder().userId(request.getUserId()).source(request.getSource())
                        .channel(request.getChannel()).outTradeNo(request.getOutTradeNo())
                        .outTradeTime(request.getOutTradeTime()).build());
        return Response.<SettlementMarketPayOrderResponseDTO>builder()
                .code(ResponseCode.SUCCESS.getCode()).info(ResponseCode.SUCCESS.getInfo())
                .data(SettlementMarketPayOrderResponseDTO.builder().userId(result.getUserId())
                        .teamId(result.getTeamId()).activityId(result.getActivityId())
                        .outTradeNo(result.getOutTradeNo()).build()).build();
    } catch (AppException e) {
        return Response.<SettlementMarketPayOrderResponseDTO>builder().code(e.getCode()).info(e.getInfo()).build();
    } catch (Exception e) {
        log.error("模拟结算接口失败", e);
        return Response.<SettlementMarketPayOrderResponseDTO>builder()
                .code(ResponseCode.UN_ERROR.getCode()).info(ResponseCode.UN_ERROR.getInfo()).build();
    }
}
