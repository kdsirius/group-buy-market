# 项目本地记忆

这里保存跨 Agent 产品也应读取的**长期协作约定与稳定项目认知**，不替代代码和进度文件。

## 读取规则

- 开始教学、验收或修改教程前，先读本目录相关文件、根 `AGENTS.md`、`docs/study/AGENTS.md` 和 `docs/learning-guide.md`。
- 业务代码、接口签名、当前分支和测试结果以仓库真实文件与 Git 为准；本目录不复制代码事实、Git 历史或临时任务状态。
- 章节完成后，只更新仍然有长期价值的偏好和流程；过时或重复内容直接修订/删除，避免记忆漂移。
- 进度、验收状态和欠账只写 `docs/learning-guide.md`；这里仅保存“应该怎样协作”和“为什么这样协作”。

## 文件

- `collaboration.md`：用户角色、前后端写作边界、验收暂停与提交门槛。
- `teaching-style.md`：短篇初学者讲解、真实测试优先、注释和 Mermaid 要求。
- `chapter-log.md`：只记录已完成章节中仍值得跨 Agent 复用的教学决策；具体状态回到学习指南。
